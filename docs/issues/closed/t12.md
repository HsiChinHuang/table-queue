## Decision

1. **react-router target line: 7.18.x (floor >= 7.18.3; registry latest 7.18.4).** The v6 line (6.30.6) is unpatchable: the backslash open-redirect bypass (CVE-2026-53669) and the constructor injection (CVE-2026-53666) are fixed only in >= 7.18.0, so the v7 migration is mandatory, not optional. react-router v8 is out of scope (separate migration).
2. **Import surface is SW's choice**: keep the `react-router-dom` v7 shim (zero import changes across the 18 files) or switch to bare `react-router` (import paths updated). AC-2 pins the resolved version, not the import surface.
3. **vitest target: 5.x** (satisfies the draft floor >= 4.1.11; it is the registry fix path). @vitest/coverage-v8 must be 5.x (floor >= 5.0.0) to pair. vitest 5 drops the standalone `vite-node` dependency, which removes the nested vite 5.4.21 / esbuild 0.21.5 copies; top-level vite 6.4.3 + esbuild 0.25.12 remain (already patched).
4. **tailwindcss 3.4.3 -> 4.x (4.3.3) is in scope and forced**: the 3.x line is EOL at 3.4.19 (the vulnerable ceiling), the braces stack-exhaustion advisory (CVE-2026-93687) has no patched release, and only the 4.3.3 tree clears the chokidar/micromatch/fast-glob/brace-expansion chain. Config migration (postcss plugin -> `@tailwindcss/postcss`, CSS `@tailwind` directives -> `@import "tailwindcss"`, theme via `@theme` or `@config` compat) is SW's detail; constraint: status colors from `_docs/ui.md` section 2 survive, build passes, suite green.
5. **`brace-expansion` lifted via `overrides`** (draft-approved mechanism) to the patched 1.x floor (>= 1.1.21): the resolved 1.1.18 under minimatch is the only remaining HIGH finding after the dependency bumps.
6. **Host binding**: remove the forced all-interfaces bind from `vite.config.ts` (default becomes Vite's 127.0.0.1). README "Mobile Testing" and `deployment.md` already document the `--host` opt-in; keep them.
7. **Suite count may move** after the vitest-major + router-major; the SW round records the new count in DoD; T13 (depends on T12) re-baselines the floors.
8. **Achievability verified at groom**: the exact bump set {tailwindcss 4.3.3, vitest ^5.0.3, @vitest/coverage-v8 ^5.0.3, react-router-dom ^7.18.4, overrides brace-expansion ^1.1.21} yields `npm audit` = 0 vulnerabilities in scratch simulation (see Context).
