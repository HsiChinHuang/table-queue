## Goal

The frontend must call backend endpoints with paths and response shapes that match `_docs/openapi.yaml`. With `VITE_USE_MOCK=false`, all core user flows (guest join, status check, staff login, call/seat, table release) must succeed against a live backend.

## Context

Platform #88 documents a measured contract drift: the frontend calls paths that do not exist on the backend, and reads response fields that do not match the contract. At main `b763183` on 2026-09-14:

- Backend live route list (GET /openapi.json, 27 paths) and `_docs/openapi.yaml` AGREE.
- Frontend base URL is `VITE_API_BASE_URL=/api/v1` and `vite.config.ts` proxies `/api` → `http://localhost:8000` with NO rewrite.
- Measured failures through that proxy include 404s on `/api/v1/public/board/1`, `/api/v1/public/waitlist`, `/api/v1/staff/login`, and a 405 on `PUT /api/v1/admin/tables/{id}`.
- Response-shape drift: `POST /api/v1/auth/login` returns `{"access_token","expires_in","token_type"}` while `frontend/src/api/auth.ts` reads `response.token`.
- Type drift: `StatusPage.tsx` calls `getBoard('branch-001')` (string) while `JoinPage.tsx` uses `VITE_BRANCH_ID=1` (integer) and the contract's `branch_id` is an integer.

Consequence: with `VITE_USE_MOCK=false`, the JoinPage renders "waitlist closed", BoardPage renders empty, and staff login cannot succeed. The app is demoable only in mock mode.

```bash
# AC-1: Extract all API paths from frontend source and verify against openapi.yaml
# Red baseline: at least one frontend path is missing from the contract (FAIL)
# Green pin: all extracted paths are found in openapi.yaml (PASS)

cd /mnt/c/Users/tw097/Desktop/ai-dev-tools-zoomcamp/wt/T32-pm

# Extract paths from frontend API calls (look for string literals matching /api/v1/...)
# This grep finds path strings in api/*.ts and pages/*.tsx
extract_paths() {
    grep -rhoE '/api/v1/[a-zA-Z0-9/_-]+' frontend/src/api/*.ts frontend/src/pages/*.tsx 2>/dev/null | sort -u
}

# Extract paths from openapi.yaml (paths section)
extract_openapi_paths() {
    grep -E '^  /' _docs/openapi.yaml 2>/dev/null | sed 's/^  //' | sed 's/:/{/g' | sed 's/}/}/g' | sort -u
}

# Get the base paths (strip branch_id, queue_number, etc. parameters)
normalize_path() {
    # Replace {param} and /{param} patterns with a generic placeholder
    echo "$1" | sed 's/{[^}]*}/{PARAM}/g'
}

# Build normalized sets
frontend_norm=$(extract_paths | while read p; do normalize_path "$p"; done | sort -u)
openapi_norm=$(extract_openapi_paths | while read p; do normalize_path "$p"; done | sort -u)

# Check each frontend path against openapi
fail_count=0
pass_count=0
for fp in $frontend_norm; do
    if echo "$openapi_norm" | grep -qxF "$fp"; then
        pass_count=$((pass_count + 1))
    else
        fail_count=$((fail_count + 1))
        echo "MISSING: $fp"
    fi
done

if [ $fail_count -eq 0 ]; then
    echo "PASS AC-1: All $pass_count frontend paths found in openapi.yaml"
else
    echo "FAIL AC-1: $fail_count paths missing from contract (red baseline)"
fi
```
