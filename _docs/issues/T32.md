## Goal

The frontend must call backend endpoints with paths and response shapes that match `_docs/openapi.yaml`. With `VITE_USE_MOCK=false`, all core user flows (guest join, status check, staff login, call/seat, table release) must succeed against a live backend.

## Context

Platform #88 documents a measured contract drift: the frontend calls paths that do not exist on the backend, and reads response fields that do not match the contract. At main `b763183` on 2026-09-14:

- Backend live route list (GET /openapi.json, 27 paths) and `_docs/openapi.yaml` AGREE.
- Frontend base URL is `VITE_API_BASE_URL=/api/v1` and `vite.config.ts` proxies `/api` → `http://localhost:8000` with NO rewrite.
- Measured failures through that proxy include 404s on `/api/v1/public/board/1`, `/api/v1/public/waitlist`, `/api/v1/staff/login`, and a 405 on `PUT /api/v1/admin/tables/{id}`.
- Response-shape drift: `POST /api/v1/auth/login` returns `{"access_token","expires_in","token_type"}` while `frontend/src/api/auth.ts` reads `response.token`.
- Type drift: `StatusPage.tsx` calls `getBoard('branch-001')` (string) while `JoinPage.tsx` uses `VITE_BRANCH_ID=1` (integer) and the contract's `branch_id` is an integer.

Consequence: with `VITE_USE_MOCK=false`, the JoinPage renders "waitlist closed", BoardPage renders empty, and staff login cannot succeed. The app is demoable only in mock mode.

- [ ] **AC-1** Contract conformance: Every base-relative path in `frontend/src/api/*.ts` (excluding test files) must map to a contract path when prefixed with `/api/v1`.

```bash
cd "$(git rev-parse --show-toplevel)"
python3 - <<'PY'
import io, re, json, os
files = [f for f in os.listdir("frontend/src/api") if f.endswith(".ts") and ".test." not in f]
src = "".join(io.open("frontend/src/api/" + f, encoding="utf-8").read() for f in files)
pattern = r"""(?:get|post|put|patch|del|delete)\s*(?:<[^>]+>)?\s*\(\s*['\"`]([^'\"`?#]+)"""
calls = {c for c in re.findall(pattern, src, re.I) if c.startswith("/")}
spec = __import__("yaml").safe_load(io.open("_docs/openapi.yaml", encoding="utf-8"))
contract = {p.rstrip("/") or "/" for p in spec["paths"]}
def concrete(p):
    p = re.sub(r"\{[^}]+\}", "*", p)
    p = re.sub(r":[0-9A-Za-z_]+", "*", p)
    p = re.sub(r"/[0-9A-Fa-f]{6,}", "/*", p)
    p = re.sub(r"/[0-9]+(?=/|$)", "/*", p)
    return p.rstrip("/") or "/"
templ = {re.sub(r"\{[^}]+\}", "*", c).rstrip("/") or "/" for c in contract}
def matches(c):
    full_path = "/api/v1" + c
    cc = concrete(full_path)
    return cc in templ or any(re.fullmatch(re.escape(t).replace(r"\*", "[^/]+"), cc) for t in templ)
bad = sorted(c for c in calls if not matches(c))
print("calls=%d unmatched=%d" % (len(calls), len(bad)))
[print("UNMATCHED", b) for b in bad]
if bad:
    print("FAIL AC-1: %d unmatched client path(s) of %d" % (len(bad), len(calls)))
else:
    print("PASS AC-1: %d unmatched client path(s) of %d" % (len(bad), len(calls)))
PY
```

Measured today: 8 unmatched paths
