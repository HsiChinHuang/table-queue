## Goal

Restore `_docs/api-examples.md` to valid markdown with balanced code fences, and ensure every one of the 28 operations in `_docs/openapi.yaml` has a matching curl example with correct method, path, and schema shape.

## Context

The file `_docs/api-examples.md` (238 lines, 6189 bytes) has only 1 unclosed fence at line 16. Everything after line 16 lost its markdown structure: headings are plain text, `bash` appears as bare words, commands are unfenced. This issue audits and fixes only `_docs/api-examples.md` to match the authoritative API definition in `_docs/openapi.yaml` (25 paths, 28 operations, tags: public, auth, staff, admin, health).

Related: `_docs/plan.md` section 6 (API design, lines 300-553), section 6.4 (AC authoring guidance, lines 640-800). `_docs/specs.md` section 11 (Error Codes, 13 error codes with `error.code`/`error.message`/`error.details` shape).
