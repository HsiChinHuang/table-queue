2. `uv run uvicorn app.main:app --reload --port 8123` - start server
3. `curl http://localhost:8123/health` - verify health endpoint returns {"status": "ok", "version": "...", "env": "development"}
4. `curl http://localhost:8123/docs` - verify Swagger UI shows /health endpoint
5. `uv run pytest` - run all backend tests

## Implementation notes

- Stack: uv + FastAPI + SQLAlchemy 2.0 + Pydantic v2 per commands.md
- uv location: ~/.local/bin/uv v0.12.12
- Python version: 3.12.3
- `uv run` may need network for dependency resolution (known risk; ACs must not depend on network availability)
- Use SQLAlchemy 2.0 style with `Mapped[]` and `mapped_column()`
- Use Pydantic v2 with `BaseSettings` for config
- Database: SQLite (dev.db) for development
- Create tables with `create_all` on startup (no Alembic in v1)
- Health endpoint returns: `{"status": "ok", "version": "0.1.0", "env": "<ENV>"}`
- Bootstrap seed data: create default Restaurant (Sunny Bistro), Branch (Taipei Xinyi), and Settings on startup if missing
