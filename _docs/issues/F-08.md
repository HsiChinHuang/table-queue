## Goal

Build `/status/:queueNumber` page for guests to view their waitlist status.

## Context

Guests join the waitlist and need to track their position in real-time. The status page is the primary guest-facing interface after joining. It shows the current status (WAITING, CALLED, SEATED, NO_SHOW, CANCELLED) with appropriate visual indicators and actions.

Per `_docs/ui.md` section 6.2 (lines 158-172):
- Mobile-first, centered `max-w-lg` layout
- If no `token` in query string, show last-3-digits input form for lookup
- Progress bar showing `Waiting → Called → Seated` flow
- Queue number displayed in `text-5xl`
- Shows `N groups ahead` and `Estimated wait: X min`
- Status-specific rendering:
  - `WAITING`: blue background, Cancel button
  - `CALLED`: orange background, countdown `mm:ss`, vibration, sound, Cancel with confirmation dialog
  - `SEATED`: green background, "You're seated. Enjoy your meal!" message
  - `NO_SHOW`: red background (Restore not available for guest)
  - `CANCELLED`: grey background, Join Again button
- Polling: every 5 seconds, refetch on window focus, immediate refetch when countdown reaches 0
- Sound toggle in top-right corner

Per `_docs/ui.md` StatusBadge section (397-403):
- WAITING: blue, label "Waiting"
- CALLED: orange, label "Called"
- SEATED: green, label "Seated"
- NO_SHOW: red, label "No-show"
- CANCELLED: grey, label "Cancelled"
- DONE: dark green, label "Done"

Per `_docs/ui.md` Countdown section (405-409):
- Display format: `mm:ss` (e.g., `09:59` for >60s, `00:59` for <60s)
- Zero countdown: `00:00` in red
- `aria-live="off"` for countdown

Per `_docs/specs.md` section 5, statuses enum:
- `WAITING`, `CALLED`, `SEATED`, `DONE`, `NO_SHOW`, `CANCELLED`

## Implementation notes

- `formatCountdown` must be a pure function exported from StatusPage.tsx for testability
- Format: `mm:ss` using `padStart(2, '0')` for both minutes and seconds
- Zero seconds should display as `00:00` (not hidden or special text)
- Reuse `StatusBadge` and `Countdown` components from F-06 (import from `@/components/StatusBadge` and `@/components/Countdown`)
- Polling via TanStack Query's `refetchInterval: 5000` (or `5 * 1000`)
- `refetchOnWindowFocus: true` for automatic refetch on focus
- Sound toggle uses `staffStore.soundEnabled` Zustand store
- Vibration uses `navigator.vibrate(200)` when CALLED
- Sound uses Web Audio API (880Hz, 0.3s beep) - see `_docs/ui.md` section 13
- ConfirmDialog for CALLED cancel action - see `_docs/ui.md` section 15
- All UI text in English only (no CJK characters)
- Mobile-first responsive design with `max-w-lg` centered layout
