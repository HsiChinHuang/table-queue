## Goal

Build `/lookup` page that allows guests to look up their waitlist status by queue number and phone last 3 digits, then navigate to the status page.

## Context

Guest lookup flow from `_docs/specs.md` Section 7: guests can look up their waitlist entry using queue number + last 3 digits of phone number. The status token equals the last 3 digits of the phone.

Related: F-05 (routing), F-06 (shared components)

UI spec: `_docs/ui.md` Section 6.3 (Lookup Page)

API contract: `GET /api/v1/waitlist/{queue_number}` from `_docs/openapi.yaml`

## Implementation notes

- Create `frontend/src/pages/public/LookupPage.tsx`
- Export pure function `normalizeQueueNumber(input: string): string` that trims and uppercases
- Use `react-router-dom` for navigation (from F-05)
- Use `Button`, `Input`, `Label` from shadcn/ui (from F-06)
- Form submission calls mock API or navigates directly
- Error state shows `No matching waitlist entry found.`
- Success navigates to `/status/{queueNumber}?token={statusToken}`
- Use Tailwind classes: `max-w-md`, `mx-auto`, `p-4`, `space-y-4`
- All UI text in English only
