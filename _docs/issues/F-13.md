## Goal

Build the `/staff/tables` page that displays all tables in a grid, allows staff to toggle AVAILABLE↔CLEANING, and release OCCUPIED tables.

## Context

This page provides staff with a visual overview of all table statuses. Staff can quickly see which tables are available, which are being cleaned, and which are occupied with guest details.

The page uses:
- `useTables` hook from F-04 API layer to fetch and poll table data
- `useUpdateTableStatus` and `useReleaseTable` hooks from F-04 for mutations
- `tables` query key group from F-03

Design reference: `_docs/ui.md` section 6.7 (Tables Page).

State machine: `_docs/specs.md` Section 5 (Table states and transitions).

## Implementation notes

- Create `frontend/src/pages/staff/TablesPage.tsx`
- Export pure function `formatOccupiedLabel(t: {queueNumber: string; partySize: number; occupiedMinutes: number}): string` returning `` `${t.queueNumber} · ${t.partySize} pax · ${t.occupiedMinutes} min` `` (note: · is U+00B7 middle dot)
- Import hooks from F-04 API layer: `useTables`, `useUpdateTableStatus`, `useReleaseTable`
- Use `ConfirmDialog` component from shadcn/ui for release confirmation
- Status colors from `_docs/ui.md` section 2:
  - AVAILABLE: `#22C55E` (green)
  - OCCUPIED: `#F97316` (orange)
  - CLEANING: `#A855F7` (purple)
- Use `useTables` hook which provides `data`, `isLoading`, `error`, and `refetch`
- Set `refetchInterval={5000}` on the tables query for 5-second polling
- Handle three table states:
  - AVAILABLE: clickable, toggles to CLEANING
  - CLEANING: clickable, toggles to AVAILABLE
  - OCCUPIED: shows occupied info, has Release Table button
- Empty state shown when `tables.length === 0`
