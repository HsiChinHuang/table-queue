## Goal

Build `/staff/login` page with PIN authentication, remember-me persistence, and error handling.

## Context

This is the staff login page for TableQueue. Staff authenticate with a shared PIN to get a JWT token.

Related docs:
- `_docs/ui.md` section 6.5 (lines 194-201): Login Page UI spec, centered `max-w-sm`
- `_docs/specs.md` section 11 (lines 454-478): Error codes `AUTH_INVALID_PIN=401`, `AUTH_RATE_LIMITED=429` (note: `AUTH_RATE_LIMITED` is outside the API contract; mock layer F-03 synthesizes it)
- Auth store: `useAuthStore` (zustand) from F-06/F-03 era - token stored under a storage key chosen by the store

Pre-located facts (authoritative):
- PIN input: `type=password` + `inputMode=numeric`
- Remember me checkbox: default checked
- Login button present
- Error message: `Invalid PIN.`
- On success: store token + navigate to `/staff/waitlist`
- Already-logged-in redirect: `/staff/waitlist`
- Remember checked → localStorage; unchecked → sessionStorage
- `AUTH_RATE_LIMITED` → `Too many attempts. Please try again later.`
- Centered `max-w-sm`
- All UI text in English

## Test requirements

- Frontend: `frontend/src/pages/staff/LoginPage.test.tsx`
  - Test `tokenStorageFor(true)` returns `'localStorage'`
  - Test `tokenStorageFor(false)` returns `'sessionStorage'`
  - Test login success navigates to `/staff/waitlist`
  - Test AUTH_INVALID_PIN shows "Invalid PIN."
  - Test AUTH_RATE_LIMITED shows "Too many attempts. Please try again later."
  - Test already-logged-in redirect
- Manual verification:
  1. Navigate to `/staff/login` when not authenticated - see login form
  2. Navigate to `/staff/login` when already authenticated - redirect to `/staff/waitlist`
  3. Enter invalid PIN - see "Invalid PIN." error
  4. Enter valid PIN with Remember me checked - token in localStorage, navigate to `/staff/waitlist`
  5. Enter valid PIN with Remember me unchecked - token in sessionStorage, navigate to `/staff/waitlist`
  6. Trigger rate limit - see "Too many attempts. Please try again later."

## Implementation notes

- Files to create:
  - `frontend/src/pages/staff/LoginPage.tsx` - main login page component
  - `frontend/src/pages/staff/LoginPage.test.tsx` - unit tests
- Key types/functions:
  - `tokenStorageFor(remember: boolean): 'localStorage' | 'sessionStorage'` - pure function for storage selection
  - `useLogin` - auth store action from F-06
  - `useAuthStore` - Zustand auth store from F-06
- Use `useNavigate` from react-router for navigation
- Use `useAuthStore` to check `isAuthenticated` for redirect guard
- Map error codes in `api/errors.ts` (F-03) - `AUTH_RATE_LIMITED` is synthesized by mock layer
- Form handling: use `react-hook-form` + zod (F-06 pattern)
- Remember me checkbox controls storage type: checked→localStorage, unchecked→sessionStorage
