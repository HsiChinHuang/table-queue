## Goal
Create `python -m app.seed` with `--reset`.



## Context

`main.py:bootstrap_defaults` inserts a Restaurant/Branch/Settings stub through raw SQL, and the app
lifespan calls `Base.metadata.create_all(bind=engine)` - but at groom time that metadata registry is
EMPTY unless something has imported `app.models`, so a fresh database ends up with no tables at all
(verified: after `TestClient(app)` against a fresh sqlite file every `select count(*)` raised
`no such table`). B-13's seed script is therefore the first thing that must import `app.models` and
call `create_all` itself; it must not lean on the app lifespan. That gap is recorded for Phase 3
integration (D-INT-3) - do not "fix" `main.py` here.

Measured in this worktree (`backend/.venv`, `uv run --no-sync`):
- `app/models.py` (B-02) columns: `Restaurant(id,name,created_at,updated_at)`,
  `Branch(id,restaurant_id,name,address,phone,timezone,business_day_cutoff_hour,open_time,close_time,...)`,
  `Settings(id,branch_id,hold_minutes,avg_seat_minutes,queue_prefix,is_waitlist_open,
  sound_enabled_default,notification_templates,staff_pin_hash,...)`,
  `Table(id,branch_id,label,capacity,section,sort_order,status,is_active,...)`,
  `WaitlistEntry(id,branch_id,queue_number,full_queue_number,queue_prefix,seq,business_date,name,
  phone,party_size,note,status,sort_order,source,hold_minutes_snapshot,cancelled_reason,table_id,
  created_at,updated_at,called_at,seated_at,closed_at)`.
- Enums: `WaitlistStatus = WAITING|CALLED|SEATED|DONE|NO_SHOW|CANCELLED`,
  `WaitlistSource = CUSTOMER|STAFF`, `CancelledReason = CUSTOMER|STAFF|CLOSED_DAY|RESET`,
  `TableStatus = AVAILABLE|OCCUPIED|CLEANING`.
- ids are `uuid.UUID`; `business_date` is `String(10)`; all timestamps are `DateTime(timezone=True)`.
- specs.md section 19 is the only data source: Restaurant `Sunny Bistro`; Branch `Taipei Xinyi`;
  address `No. 123, Example Rd., Xinyi Dist., Taipei City 110, Taiwan`; phone `02-1234-5678`;
  hours `11:00-21:00`; tables A1-A4 (2), B1-B4 (4), C1-C2 (6); 5 WAITING + 1 CALLED (`called_at`
  3 minutes ago) + 1 SEATED on B1 + 1 NO_SHOW + 1 CANCELLED = 9 entries; all
  `business_date = today`; phones `0900-000-001`..`0900-000-009`; Staff PIN `1234`.
- `timezone` / `business_day_cutoff_hour` are not repeated in section 19: section 7 fixes the cutoff
  at 4 and section 13 fixes `Asia/Taipei` (section 6 gives both as column defaults).

## Implementation notes

- **Files: `backend/app/seed.py` + `backend/tests/test_seed.py` only.** `python -m app.seed` works
  from a plain module file - no `app/__main__.py` is needed - as long as it runs with `backend` as
  cwd (all AC blocks do `( cd backend && ... )`).
- **Create the schema yourself.** `import app.models` (that is what registers the tables on
  `Base.metadata`) and call `Base.metadata.create_all(engine)`. Do NOT rely on the app lifespan: at
  groom time `TestClient(app)` on a fresh sqlite file produced a database with **no tables at all**,
  because the lifespan's `create_all` saw an empty registry.
- **`bootstrap_defaults` is buggy in exactly that spot** - it inserts Settings without
  `sound_enabled_default` and dies with `IntegrityError: NOT NULL constraint failed:
  settings.sound_enabled_default`. Do not copy that INSERT; set
  `sound_enabled_default=True` explicitly. Do not fix `main.py` either (out of scope; recorded as
  D-INT-3 for Phase 3).
- **Hash the PIN with the `bcrypt` package, NOT `passlib`.** Verified in this venv
  (`passlib 1.7.4` + `bcrypt 5.0.0`): `CryptContext(schemes=["bcrypt"]).hash("1234")` raises
  `ValueError: password cannot be longer than 72 bytes` (passlib probes a legacy bug hash and
  `bcrypt.__about__` is gone in bcrypt 5). Working recipe, both directions verified:
  `bcrypt.hashpw("1234".encode(), bcrypt.gensalt(rounds=10)).decode()` -> `$2b$...` (60 chars), and
  `bcrypt.checkpw(pin.encode(), stored.encode())`.
- **`app/security.py` does not exist yet** (B-05 owns it) - do not create or import it. Keep hashing
  inside `seed.py`.
- **The seeded PIN is `1234` from specs section 19**, not `settings.staff_pin`. AC-4 asserts
  `checkpw(0000)` is False while the probe runs with `STAFF_PIN=0000`, precisely to catch an
  implementation that hashes the env var.
- **Phones keep the dashes** exactly as specs writes them (`0900-000-001`..`0900-000-009`); 9 entries,
  one phone each. The API normalizes phones later (B-06); the seed just writes section 19.
- **`business_date` is `String(10)`** -> write `date.isoformat()`. Compute it the way section 8
  defines it, `(datetime.now(ZoneInfo("Asia/Taipei")) - timedelta(hours=4)).date()`, because AC-6/AC-7
  recompute the same expression - a plain `date.today()` mismatches during the first 4 hours of a UTC day.
- **Timestamps are `DateTime(timezone=True)`** -> write tz-aware UTC (`datetime.now(UTC)`,
  minus 3 minutes for CALLED). sqlite hands naive strings back, and AC-8 parses them assuming UTC, so
  never write naive or Taipei-local values. CALLED must be ~3 minutes old (AC-8 accepts 60..300 s);
  anything >= 10 minutes would already be NO_SHOW-eligible.
- **`--reset`**: delete child-first (`waitlist_entries`, then `tables`) and rebuild the whole fixture;
  re-creating Restaurant/Branch/Settings is fine as long as the counts stay 1/1/1 (AC-10 compares only
  table/entry counts and requires the entry IDS to change). AC-11 proves hand-made rows are gone.
- **Messages are graded**: a no-op run must print something matching `skip|already|exists` (AC-9);
  a `--reset` run must print something matching `reset|clear|delete` (AC-10). Both exit 0.
- **Shape**: `argparse` with `--reset`; `def main(argv: list[str] | None = None) -> int` and
  `if __name__ == "__main__": raise SystemExit(main())` (AC-11b greps for `def main` and `__main__`).
- Stay lint-clean under this repo's ruff config (E/F/B/UP/SIM/N/I, 100 cols): `from datetime import
  UTC`, builtin generics (`list[str]`), no unused imports, no `except Exception: pass`.
- `structlog` / `rich` are not dependencies (AC-13 greps for structlog): plain `print()` output.
- Guest names and notes must be ASCII English (CJK ratchet): Alice, Bob, Carol, David, Erin, Frank,
  Grace, Henry, Iris; notes like "window seat", "high chair needed", "birthday dinner", "quiet area",
  "near exit".
