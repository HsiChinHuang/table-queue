## Goal

`_docs/issue-map.json` is the local-ID to Platform-issue-number bridge that `ready.py` and the
Orchestrator load. It has no entry for `P0-13` (Platform #46, closed 2026-09-11), and it never had one
for `P0-12` (an ID that exists nowhere else either). Audit every entry against the Platform and fill
the gaps, so a closed issue is never invisible to the map.

## Context

`_docs/team/sa.md` phase P3 makes the SA responsible for writing `issue-map.json` when it creates the
Platform Issues. Issues created later by other routes have no step that updates the map:

- `P0-13` was orchestrator-authored, its work landed on `main` before the issue file existed, and the
  map was never touched. Verified today: the map has 45 entries, its highest Platform number is 45
  (`D-03`), and `'P0-13' in map` is `False`.
- A new issue created after the SA run (`B-15` #47, `F-16` #48, `P0-16` #49, created 2026-09-11) also
  has no map entry until this gap is closed.

`_docs/team/orchestrator.md` step 0b loads the map to translate IDs. A missing entry means
`ready.py` and any number->file lookup silently miss the issue, and the mirror DoD ("`mirror-check.py
<number>` matches `_docs/issues/<ID>.md`") cannot be evaluated by ID alone.

Also recorded here because it is a live hazard: two untracked ghost files (`P0-14.md`, `P0-15.md`)
claimed `platform_issue: 47` and `48` when issues #47 and #48 did not exist. They were deleted
uncommitted, and #47/#48 were then legitimately allocated to `B-15` and `F-16`. If those ghost files
are ever restored from a local copy, their `platform_issue:` values now point at unrelated issues.

- [ ] **AC-2** Every issue file under `_docs/issues/` has a map entry, and the entry equals the `platform_issue:` value in that file's front matter.

```bash

import json,os,re
m=json.load(open('_docs/issue-map.json',encoding='utf-8')); m=m.get('issues',m)
bad=[]
for fn in sorted(os.listdir('_docs/issues')):
    if not fn.endswith('.md'): continue
    ident=fn[:-3]
    raw=open(f'_docs/issues/{fn}',encoding='utf-8',errors='replace').read()
    fm=raw.split('---')[1] if raw.count('---')>=2 else ''
    num=re.search(r'^platform_issue:\s*(\d+)',fm,re.M)
    if ident not in m: bad.append(f'MISSING {ident} (front matter says {num.group(1) if num else "none"})')

    elif not num: bad.append(f'NO platform_issue in front matter: {ident}')
if bad:
    print('FAIL AC-2:'); [print('   ',b) for b in bad]
else:
    print('PASS AC-2: every issue file has a matching map entry and front-matter number')
PY
```

```bash

python3 - <<'PY'
import collections, json, urllib.request
m=json.load(open('_docs/issue-map.json',encoding='utf-8')); m=m.get('issues',m)
dup=[n for n,c in collections.Counter(m.values()).items() if c>1]

    try:
        with urllib.request.urlopen(urllib.request.Request(url,headers={'User-Agent':'ac'}),timeout=30) as r:
            rows=json.loads(r.read().decode())

    if len(rows)<100: break

absent=sorted(want-seen)
if absent:
    print('FAIL AC-3: map numbers with no Platform issue: '+' '.join(str(n) for n in absent))
else:
    print(f'PASS AC-3: all {len(m)} map entries point at real, unshared Platform issues')
PY
```
