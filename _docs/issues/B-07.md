## Goal

Give the staff surface its waitlist: one list endpoint that filters, searches, pages and sorts the
day's entries with the lazy no-show applied before the answer is produced, and nine action endpoints
(call, seat, no-show, restore, revert, cancel, edit, reorder) that move an entry along the section 5
state machine and keep the table row and the entry row in step.

- **R-B07-1 (the reorder mismatch code is 409, not 422).** `POST /api/v1/staff/waitlist/reorder`
  declares exactly two non-success responses in `_docs/openapi.yaml`: `401` (`Unauthorized`) and
  `422` (`ValidationError`). It does **not** declare `409`, unlike the seven action operations that
  carry `WaitlistInvalidStatus`. `app/schemas.ReorderWaitlistRequest` validates only that
  `ordered_ids` is a list of UUID strings, so a list of well-formed UUIDs that is not exactly the
  current `WAITING` + `CALLED` set is not a schema failure - it is the staff user asking for an
  order over a queue that has changed under them, which is section 11's `CONFLICT` (409) or
  `WAITLIST_INVALID_STATUS` (409). The contract's 402-free answer wins: a set mismatch is 409 and
  the code must be one of the 409s section 11 defines, `CONFLICT` or `WAITLIST_INVALID_STATUS`.
  422 stays reserved for what the schema itself rejects (a non-UUID member, a missing key), and AC-14
  measures both halves of that line.
- **R-B07-2 (`search` has no SQL pattern anywhere in the contract).** `WaitlistFilterStatus` and the

- **R-B07-3 (`restore` returns the row to `WAITING` with a cleared hold, and the AC says which

   transition is persisted, not computed per read. AC-3 pins the observable pair (the list answer
   *and* a second list answer both say `NO_SHOW`), which is the persisted reading and the only one
   the merged code can satisfy.
2. **What does `phone_masked` actually print?** `app/schemas.mask_phone` is a shape-preserving
   mask, not the one template the openapi example shows. Measured on the merged tree:
   `0900-000-001` gives `0900-***-001`, `0912345678` gives `*******678`, `02-123-4567` gives
   `02-***-4567`. So the invariant is "the last three digits survive and everything left of them is
   replaced by asterisks, one per hidden character", not "the string starts with `0900-`". AC-4
   asserts the invariant on a row whose phone is typed in the contract's own form, so the printed
   value is exactly the contract example `0900-***-001` while the check stays true for the other
   shapes the merged mask produces.

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result


def swap_uuid_type():

    ``models.py`` evaluates ``UUID(as_uuid=True)`` at class-definition time, so the only hook
    that reaches it is the module attribute, rebound before the first ``import app.models``. An
    engine-level ``type_encoders`` entry cannot do this: ``URL.get_dialect`` builds the dialect
    from scratch and copies only ``connect_args`` and ``execution_options``, so an encoder
    handed to ``create_engine`` never reaches the first statement.
    """
    sa.UUID = TextUUID
    import sqlalchemy.sql.sqltypes as sqltypes

    sqltypes.UUID = TextUUID

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result

    handed to ``create_engine`` never reaches the first statement.

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result


def swap_uuid_type():
    """Make ``sqlalchemy.UUID`` mean :class:`TextUUID` before ``app.models`` is imported.

    ``models.py`` evaluates ``UUID(as_uuid=True)`` at class-definition time, so the only hook
    that reaches it is the module attribute, rebound before the first ``import app.models``. An
    engine-level ``type_encoders`` entry cannot do this: ``URL.get_dialect`` builds the dialect
    from scratch and copies only ``connect_args`` and ``execution_options``, so an encoder
    handed to ``create_engine`` never reaches the first statement.
    """
    sa.UUID = TextUUID
    import sqlalchemy.sql.sqltypes as sqltypes

    sqltypes.UUID = TextUUID

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result

    ``models.py`` evaluates ``UUID(as_uuid=True)`` at class-definition time, so the only hook
    that reaches it is the module attribute, rebound before the first ``import app.models``. An
    engine-level ``type_encoders`` entry cannot do this: ``URL.get_dialect`` builds the dialect
    from scratch and copies only ``connect_args`` and ``execution_options``, so an encoder
    handed to ``create_engine`` never reaches the first statement.

    sa.UUID = TextUUID
    import sqlalchemy.sql.sqltypes as sqltypes

    sqltypes.UUID = TextUUID

    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.

    cache_ok = True

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result

class TextUUID(String):
    """A uuid stored as text, which is what ``sqlalchemy.UUID`` has to mean for a probe.

    A ``String`` subclass whose ``load_dialect_impl`` answers itself, so no dialect gets to
    swap its native ``UUID`` back in. ``cache_ok`` because one instance is shared across the
    whole schema. The bind side accepts ``str`` or ``uuid.UUID`` and writes 32-character hex;
    the result side parses it back to ``uuid.UUID``, which is the round trip the shipped type
    documents and this driver will not give.
    """

    __visit_name__ = "CHAR"
    cache_ok = True

    def __init__(self, *args, **kwargs):
        """Absorb the keyword arguments the shipped column is spelled with."""
        kwargs.pop("native_uuid", None)
        kwargs.pop("as_uuid", None)
        kwargs.setdefault("length", 32)
        super().__init__(*args, **kwargs)

    def load_dialect_impl(self, dialect):
        return dialect.type_descriptor(self)

    def bind_processor(self, dialect):
        def bind(value):
            if value is None:
                return None
            return value.hex if isinstance(value, _pyUUID) else str(value).replace("-", "")

        return bind

    def result_processor(self, dialect, coltype):
        def result(value):
            if value is None or isinstance(value, _pyUUID):
                return value
            text = str(value)
            if "-" in text:
                return _pyUUID(text)
            return _pyUUID(text[:8] + "-" + text[8:12] + "-" + text[12:16]
                           + "-" + text[16:20] + "-" + text[20:])

        return result
