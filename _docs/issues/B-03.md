- Table requests: label/capacity/section bounds; `UpdateTableStatusRequest` accepts AVAILABLE/CLEANING and rejects OCCUPIED and garbage.
- Settings: the four AC-11 bounds/patterns, plus the empty-patch (partial update) case.
- `ReorderWaitlistRequest.ordered_ids` is a list of UUID strings; `SeatWaitlistRequest.table_id` is a UUID.
- Response schemas: `from_attributes=True` proven against a real in-memory SQLite row (AC-13 shape) and `extra="forbid"` behaviour (AC-7).
- Enums: values come from `app.models` (AC-12) - assert identity, not string equality.
- `ResetDataRequest.confirm` only accepts the literal `RESET`; `CancelWaitlistRequest` accepts `token` alone, `phone_last3` alone, both, or neither.

## Implementation notes
- openapi.yaml is the field-name authority (issue Constraint). Its settings fields are
  `hold_minutes` / `avg_seat_minutes` / `queue_prefix` / `is_waitlist_open`; the F-03 mock client
  still uses `call_timeout_minutes` / `waitlist_enabled`. Do NOT rename either side here - the
  reconciliation is the Phase-3 integration issue (D-INT).
- Import the status/source/reason enums from `app.models` (B-02) instead of re-declaring string
  Literals; `UpdateTableStatusRequest.status` is the deliberate subset AVAILABLE|CLEANING
  (openapi enum), which is NOT `models.TableStatus`, so it may be a separate `Literal`/enum.
- `ErrorResponse.error` is an inline object in openapi, so it needs its own model (`ErrorBody`)
  referenced from `ErrorResponse.error`.
- `BoardResponse.current_called` / `next_up` and `TableResponse.current_waitlist` are inline
  objects in openapi: a small nested model or `dict` is acceptable, but AC-4 pins the field NAMES
  on the parent, not the children.
- Nullable openapi fields (`nullable: true`) map to `T | None` with a default of `None`.
- Every AC block that imports `app.models` also imports `app.config`, which FAILS FAST on
  missing env. The blocks therefore all run with
  `DATABASE_URL=... JWT_SECRET=... JWT_EXPIRE_HOURS=1 STAFF_PIN=0000 ENV="test"`; without
  `ENV="test"` sqlalchemy `echo=True` prints every statement and buries the AC verdict line.
- specs.md section 7 fixes the accepted phone shapes: mobile `09xx-xxx-xxx` (10 digits) and
  landline `02-xxxx-xxxx` (10 digits). Other Taiwanese area codes are out of scope - do not
  widen the regex beyond that without a ruling.
- AC-13 builds ORM rows in FK order with `flush()` (Restaurant -> Branch) because `Branch`
  needs `restaurant.id` from an autoincrement primary key; `add_all()` alone leaves it NULL.
- Do not add `model_config` to request schemas that would forbid extras unless openapi says
  `additionalProperties: false`; partial-update PATCH bodies must keep accepting subsets.
- `backend/.venv` does not exist in a fresh worktree: run `cd backend && uv sync` first
  (`uv sync --extra dev` is wrong - dev deps are in `[dependency-groups]`). The venv's python is
  what every AC block above uses (`DATABASE_URL="sqlite:///./_b03ac.db" JWT_SECRET="ac-secret" JWT_EXPIRE_HOURS=1 STAFF_PIN="0000" ENV="test" backend/.venv/bin/python`), and PyYAML is importable from it.
