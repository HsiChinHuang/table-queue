## Implementation notes

Files to create:
- `frontend/src/components/StatusBadge.tsx` - badge with status color from ui.md section 2
- `frontend/src/components/Countdown.tsx` - uses useCountdown hook, red when remainingSeconds=0
- `frontend/src/components/WaitlistCard.tsx` - displays queue number, name, party size, time, actions
- `frontend/src/components/TableCard.tsx` - displays table label, capacity, status, occupied info
- `frontend/src/components/EmptyState.tsx` - generic empty state with icon/title/description/action
- `frontend/src/components/LoadingSkeleton.tsx` - supports card/list/form/board variants
- `frontend/src/components/ConfirmDialog.tsx` - uses shadcn Dialog, supports danger/default variant
- `frontend/src/components/ConnectionBanner.tsx` - shows after 3 failures, hides on recovery
- `frontend/src/components/SoundToggle.tsx` - Zustand store toggle with localStorage persistence
- `frontend/src/components/QrCode.tsx` - wraps qrcode.react with configured props
- `frontend/src/hooks/useCountdown.ts` - timer hook with remainingSeconds and onComplete callback

Key patterns:
- Use Tailwind semantic color classes (bg-waiting, bg-called, etc.) from ui.md section 2
- All icon buttons must have aria-label per ui.md section 11
- StatusBadge uses `aria-live="polite"` per ui.md section 19
- Countdown uses `aria-live="off"` per ui.md section 19
- No hex color literals in components; use theme tokens only
- SoundToggle uses `staffStore` from Zustand per AGENTS.md section 8
