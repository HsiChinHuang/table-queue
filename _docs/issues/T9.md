## Reason (audit provenance)

SEC AUDIT HIGH (A-2 A-9, D-5): login authenticates against plaintext env PIN whenever DB hash absent and default bootstrap ALWAYS leaves it absent; 12h tokens carry no jti and survive PIN rotation. Severity HIGH.

## Acceptance

bootstrap writes staff_pin_hash non-null; _pin_matches never compares against settings.staff_pin plaintext (removed or used only to seed the hash once at first boot); comparison constant-time; change-pin rotates a token-generation secret or records a revocation instant so pre-rotation JWTs are refused; measured: old token 401s after rotation
