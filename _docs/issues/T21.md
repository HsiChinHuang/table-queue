## Reason (audit provenance)

SEC AUDIT HIGH (A-14, D-3, D-4): default env writes guest name + FULL PHONE + PIN hashes to stdout via bound-parameter echo; access log records ?token=...&phone_last3=... directly contradicting _docs/specs.md:593-598; 500 tracebacks spam logs per attempt. Severity HIGH.

## Acceptance

SQL echo never on by default (see ENV issue) AND parameter values never logged regardless of level; unhandled-exception logging emits traceback WITHOUT [SQL:...]/[parameters:...] binding lines (logger config pins sqlalchemy.engine to WARNING); uvicorn access log masks query strings on credential-carrying paths (/status lookup family) at minimum; no PIN/token/Authorization value in any app-level log (live probe re-runs D-4's capture clean); specs.md Token-not-logged now TRUE end-to-end
