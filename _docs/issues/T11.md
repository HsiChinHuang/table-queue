## Reason (audit provenance)

SEC AUDIT LOW-but-structural, touches specs (A-12 client half C-6): derived secret-free token is permanent and unrotatable; 3-digit tail = 1000-key space authorizing CANCEL; token+phone tail sit in URL/history/logs. Two lanes found both halves. Severity medium overall.

## Acceptance

status capability is a server-minted opaque value >=128-bit returned at join time; derived-from-row-data scheme and 3-digit fallback removed or gated (cancel requires the minted capability); frontend stop putting tokens in query strings (memory or hash transport); Referer-Policy no-referrer on public app; specs.md token section updated to match; last-3 lookup remains as a READ-only lookup factor if product wants it
