## Reason (audit provenance)

SEC AUDIT HIGH (A-3, D-2): with ENV unset one staff token wiped the store via /admin/reset and rewrote the PIN to the published 1234; echo=True leaked PII by the same default. Severity HIGH.

## Acceptance

app refuses to start with ENV unset (no silent development default) OR defaults to a non-development value; /admin/reset 403s unless ENV=development is set EXPLICITLY; SQLAlchemy echo never enabled by default; /health env field does not reflect an implicit default; tests pin all three
