## Goal

Make the documented onboarding and development commands work from a clean clone without undocumented manual steps (symlinks, PATH edits). A new contributor should be able to follow README/_docs/SETUP.md and have `make seed`, `make dev`, `make test-backend` succeed as documented.

## Context

**Related**: Platform #89

**Measured defect** (taken at main `b763183` on 2026-09-14):
- `make seed` fails with `/bin/sh: 1: ../.venv/bin/python: not found` (rc=127) because every Makefile target resolves `../.venv` = repo-root .venv, and no repo-root .venv exists in a clean clone. `_docs/state/OPERATOR-ITEMS.md` section 3 records these targets work "only with a root .venv symlink present" — an undocumented manual step.
- `make -n dev` prints the backend line with trailing `&` then `cd frontend && npm run dev`: the documented single-command dev start starts only the frontend.
- `make setup` = `python3 -m venv backend/.venv` + `pip install -e backend`. `pip install -e` cannot read `[dependency-groups] dev` in `backend/pyproject.toml`, so pytest/httpx/freezegun/ruff are NOT installed and `make test-backend` fails for an environment reason.
- Frontend test command drift: `frontend/package.json` `"test": "vitest"` is WATCH mode — `npm run test` never exits. Working command: `npm run test -- --run` (228 tests / 27 files, ~12s).
- `README.md` Prerequisites call `make` optional while Getting Started is make targets; the README note block says "None of them exists in this checkout today" about files delivered by F-01.
- Toolchain reality: `python` does not exist (only `python3`); system node is v18 while `.nvmrc` says 20.

**Formalized from**: `_docs/state/OPERATOR-ITEMS.md` section 3 by Orchestrator boot-7.
