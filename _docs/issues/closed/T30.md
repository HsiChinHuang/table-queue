## Reason (audit provenance)

SEC AUDIT HIGH (C-1 C-2 C-3): remember-me OFF still lands TWO durable localStorage copies (jsdom-proven); removeItem count in product code = 0 so logout never clears the sessionStorage copy - live JWT readable on shared front-desk hardware after logout; 401 clears 1 of 3 copies; two stores disagree so the app can be logged-out and authenticated at once. Severity HIGH.

## Goal

When this is done: the staff JWT lives in exactly one of the four storage slots - the single session store's own persistence - with remember-me choosing the slot (ON = localStorage, OFF = sessionStorage with zero durable copies), and BOTH the logout button and the 401 handler sweep all four slots plus the in-memory state, so a logged-out shared front-desk terminal holds no live JWT and an expired session can never leave stale copies behind.
