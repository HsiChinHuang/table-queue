### Parsing traps found while measuring, which is why the checks are written this way

- `grep -c "``" _docs/ui.md` returns **434, exit 0** - inside double quotes the backticks are command
  substitution, so an empty pattern matches every line. Any fence check must use single quotes
  (`grep -c '^```'`) or python3; that single-quoted form returns **0, exit 1**, and 0 is the pass.
- The `(non-goal)` titles need `grep -F` or escaped parens: `grep -cE '^## 17\. Dark Mode (non-goal)'`
  returns **0, exit 1** (empty capture group) while `grep -cF '## 17. Dark Mode (non-goal)'` returns 1.
- `wc -l` and `awk 'END{print NR}'` disagree by 1 (433 vs 434) because the last line has no newline;
  the ACs name which one they mean.
- The section-2 tables are the only place `#RRGGBB` appears besides `### QrCode props`, so a
  whole-file hex count (22) and a section-2 count (20) must not be compared to each other.
- 10 lines carry an em dash - the file title `_docs/ui.md:1` and the 9 `### 6.x` page headings -
  5 carry an arrow, 2 carry an en dash inside a numeric range (`_docs/ui.md:236` `5-15`,
  `_docs/ui.md:260` `3-5`) and 1 carries `U+2265` (`:300`); a title or copy match must not assume
  ASCII, and `grep '>= 4.5' _docs/ui.md` returns 0 matches (exit 1) because of that character.
