## Goal

Create the monorepo structure with `backend/`, `frontend/`, `_docs/`, root `package.json`, `Makefile`, `.gitignore`, `.editorconfig`, `.nvmrc`.

## Context

This issue establishes the foundational repo structure for TableQueue. The monorepo layout follows `_docs/specs.md` section 5 (Project Structure). SW will create the files; PM here defines exactly what "done" looks like.

Related: P0-08 (requirements.md), P0-09 (AGENTS.md), P0-10 (specs.md)

Design note: `uv` is NOT installed on all developer machines and node v18.19.1 exists while `.nvmrc` demands v20. Therefore `make setup` must include a fallback path: if `uv` is absent, create `backend/.venv` with `python3 -m venv` and install via `backend/.venv/bin/python -m pip install -e backend`. This fallback is documented in Implementation notes and recorded here as an Orchestrator-relevant design note.

## Implementation notes

- Create directories: `backend/app/`, `frontend/src/`, `_docs/` (already exists)
- Create files:
  - `backend/pyproject.toml` with FastAPI, uv, SQLAlchemy, Pydantic, pytest deps
  - `backend/app/__init__.py`, `backend/app/main.py`, `backend/app/database.py`, `backend/app/models.py`, `backend/app/schemas.py`
  - `frontend/package.json` with React, Vite, TypeScript, Tailwind, shadcn/ui, TanStack Query, Zustand deps
  - `frontend/src/main.tsx`, `frontend/src/App.tsx`
  - Root `package.json` with `concurrently` and all scripts
  - `Makefile` with all 10 targets
  - `.gitignore` with all 10 entries
  - `.editorconfig` with UTF-8, LF, Python 4-space, TS/JSON/MD 2-space
  - `.nvmrc` with `20`
- `make setup` logic:
  - If `uv` exists: `cd backend && uv sync`
  - Else: `python3 -m venv backend/.venv && backend/.venv/bin/python -m pip install -e backend`
  - Frontend: `cd frontend && npm install`
- Do not create `dev.db`, `.env`, or any seed data (that's F-02+)
