## Test requirements

Create three new test modules. Do not add dependencies to `pyproject.toml`.

- `backend/tests/test_errors.py` - >= 10 tests: catalogue equals the specs.md section 11
  table parsed out of `_docs/specs.md` (2 tests: dict equality + set equality, so an
  invented or missing code fails), one parametrized test over `sorted(ERROR_CODES)`
  asserting `AppError(code).status_code`, envelope rendering with and without
  `details`, explicit message/status override, `AppError` is raisable. Handler tests
  use a FRESH `FastAPI()` + `register_error_handlers(api)` +
  `TestClient(..., raise_server_exceptions=False)` with three probe routes (AppError,
  pydantic 422 with a named field, `RuntimeError("SECRET-CANARY")`), asserting 409/422/500,
  `error.code`, and that neither the canary nor "Traceback" appears in the 500 body.
- `backend/tests/test_dependencies.py` - >= 9 tests: 5 rejected-token cases (missing,
  wrong scheme, malformed, expired, wrong secret) all `401` + `AUTH_TOKEN_EXPIRED`,
  valid token decodes, `get_now()` tz-aware UTC, `bearer_scheme` is
  `HTTPBearer(auto_error=False)` with scheme "bearer", `inspect.isgeneratorfunction(get_db)`,
  and the connection-return probe (AC-8) using `event.listen(engine, "checkin", fn)`.
- `backend/tests/test_middleware.py` - >= 6 tests: unique uuid4 `X-Request-ID`, echoed
  caller-supplied id, three security headers on `/health` and `/docs`, CORS allowlist
  from env (listed origin gets `access-control-allow-origin`, unlisted does not), and a
  slowapi route called twice returning 429 + `RATE_LIMITED`.

Rules that matter (all learned by running the AC blocks):
- Locate `specs.md` from `Path(__file__).resolve().parents[2] / "_docs" / "specs.md"`,
  never the plain relative `"_docs/specs.md"`: pytest runs with cwd=`backend` and a relative path raises
  `FileNotFoundError`, which turns two honest tests into false reds.
- Wire probe routes with the exported `Staff` alias (`Annotated[dict, Depends(...)]`),
  NOT `staff: dict = Depends(get_current_staff)`: ruff B008 rejects `Depends()` in a
  signature default, and `pyproject.toml` is out of scope, so the lint rule is not
  switchable-off.
- `event.remove(engine, "checkin", fn)` needs the SAME callable that `event.listen`
  received - two separate `lambda *args:` literals raise
  `InvalidRequestError: No listeners found`.
- Ruff in this repo flags `assert ERROR_CODES == parse_specs_error_codes()` as SIM300
  (Yoda condition). Write it as
  `assert parse_specs_error_codes() == ERROR_CODES  # SIM300: ALL_CAPS on the right`.
- Keep the test app in a fixture, and register any `/test-only/...` route inside the
  test that uses it, so handler/middleware routes never leak between modules.
- Baseline for AC-16 grows from 12 to >= 48 passing tests (12 existing + ~36 new).

## Implementation notes

Design rulings (probed green at groom time; the AC blocks are the authority, these notes
explain how to satisfy them without tripping the repo lint config):

- **Route style vs ruff B008.** AC-9/AC-15 attach their probe routes with a decorator and
  a `Depends(...)` signature default (`@app.get("/_ac9/whoami")` +
  `staff: dict = Depends(get_current_staff)`). The AC blocks never run ruff, so those
  probes are fine as written - do not "fix" them. But ruff DOES run over
  `backend/tests/**` (AC-16), so your own test modules must wire routes through the
  exported `Annotated` aliases instead of `= Depends(...)` defaults. In
  `app.dependencies` use `def get_current_staff(credentials:
  Annotated[HTTPAuthorizationCredentials | None, Depends(bearer_scheme)])`, and export
  `DbSession = Annotated[Session, Depends(get_db)]` plus
  `Staff = Annotated[dict, Depends(get_current_staff)]` for B-05+ routers. `Annotated`
  is not flagged by B008; `pyproject.toml` is out of scope so the rule cannot be disabled.
- **`get_db` is a re-export, not a copy.** AC-7 wants `app.dependencies.get_db` and AC-8
  wants a session whose connection returns to the SAME pool as `app.database.engine`,
  so do `from app.database import get_db` in `dependencies.py`; do not wrap it.
  Keep the `yield` in `finally`/close semantics so AC-8's `checkin` listener fires.
- **Every AC block that imports `app.config` sets `ENV="test"`.** `config.py` fails fast
  without `DATABASE_URL` / `JWT_SECRET` / `STAFF_PIN`, and when `env == "development"`
  SQLAlchemy echo turns on and buries the verdict line under thousands of `BEGIN(...)`
  log lines. Always run your own probes the same way the AC blocks do.
- **`checkin` listeners take two arguments.** `event.listen(engine, "checkin", fn)` calls
  `fn(engine, connection)`; `lambda conn=None: ...` raises `TypeError: <lambda>() got an
  unexpected keyword argument 'connection'`, which AC-8 reports as a crash. Use
  `lambda *args` / `def fn(*args)`.
- **slowapi needs a typed `Request`.** A route wrapped by `@limiter.limit("1/minute")`
  must annotate `request: Request`, otherwise slowapi cannot find the request object and
  FastAPI answers 422 `type=missing, loc=["body","request"]` instead of ever reaching the
  limiter (AC-15 then sees 422-with-`VALIDATION_ERROR`, not 429 `RATE_LIMITED`).
- **`HTTPBearer` scheme source (FastAPI 0.141).** `bearer_scheme.scheme_name` is the CLASS
  NAME (`"HTTPBearer"`), not the auth scheme; the real value lives at
  `bearer_scheme.model.model_fields["scheme"].default == "bearer"`. AC-10 reads the
  latter. Construct with `HTTPBearer(auto_error=False)` so a missing header reaches
  `get_current_staff` (returning None) instead of short-circuiting into FastAPI's
  `{"detail": ...}` shape - that is the whole point of AC-9's "missing header" case.
- **`structlog` is NOT a dependency.** `deployment.md` lists it under "Future". AC-17
  greps the dependency list and the repo for it, and `pyproject.toml` is out of scope:
  implement request-id / security headers as plain `@app.middleware("http")` (or a small
  `app/middleware.py`) and log with stdlib `logging`.
- **CORS comes from settings at import/startup time.** `config.py` reads `CORS_ORIGINS`
  once (`get_settings()` is cached) and `main.py` must build
  `CORSMiddleware(allow_origins=settings.cors_origins, ...)`. AC-14 launches a SUBPROCESS
  with `CORS_ORIGINS=http://listed.test`, so the allowlist must genuinely come from env -
  do not hardcode `["http://localhost:5173"]`, and do not read `os.environ` inside a
  request handler either (the test also asserts the unlisted origin gets no header).
- **`app.state.limiter` is required, not optional.** SlowAPIMiddleware raises at request
  time if `app.state.limiter` is unset; register it before adding
  `SlowAPIMiddleware` (AC-1/AC-16 import `app.main.limiter`, so the limiter object must be
  module-level in `app/main.py` - `limiter = Limiter(key_func=get_remote_address)`).
- **Register the `Exception` handler last and never echo the traceback.** Return
  `JSONResponse(status_code=500, content=AppError("INTERNAL_ERROR").to_payload())`;
  AC-6 asserts neither the original exception message nor the word "Traceback" appears.
  Log it (`logging.getLogger(__name__).exception(...)`) rather than swallowing it.
- **`X-Request-ID` must be uuid4.** AC-12 validates with `uuid.UUID(v).version == 4`, so
  `uuid4().hex` (no dashes) is fine but a truncated id is not; echo the caller's value
  verbatim and set the header on every response path, including the 500 envelope.
- **`register_error_handlers(app)` must be idempotent-ish and reusable.** AC-4..AC-6 build
  a fresh `FastAPI()` and call it; do not rely on `app.main.app` state inside it.

Environment: run everything through `uv run --no-sync` with
`export PATH="$HOME/.local/bin:$PATH"` first (uv lives in `~/.local/bin`), and use
`backend/.venv/bin/python` or `python3` - plain `python` does not exist in this WSL
(exit 127 killed one B-03 run). A failing `bash` call is information, not the end of a run.

## Dependencies

- B-01 (`app/config.py`, `app/database.py`, `app/main.py` `/health`, lifespan)
- B-02 provides `app/database.py:get_db` and `engine` - AC-8 asserts the connection returns
  to that same pool, so `dependencies.get_db` must be a re-export, not a copy
- `_docs/specs.md` section 11 is the error-code contract source; AC-2 parses it live

## Out of scope

- `pyproject.toml` - no new dependencies, no lint-rule relaxations
- `app/schemas.py` (B-03) and `app/models.py` (B-02) - no response models defined here
- Route implementations, service layer, repositories (B-05, B-06, B-08, B-10, B-11)
- Per-route rate-limit tuning: only the shared limiter and the 429 envelope are in scope
- Any `structlog`, Sentry or OpenTelemetry integration (not dependencies of this repo)
