## Goal

Give a Platform Issue to documentation work that was directed by the owner and landed on `main`
before any issue existed to own it: `ac299d2` (slim `AGENTS.md` to a route map, add

## Context

The repo convention, established by P0-09 AC-18 and P0-10's route list, is that every docs edit
names an owning Platform Issue. The owner directed this change directly, so it was landed to keep
`main` coherent and the missing traceability was recorded as debt. This issue closes that debt.

`AGENTS.md` had grown to 572 lines and was the **third** copy of the same rules:
`_docs/requirements.md` (594 lines) already restates all 17 sections, and `_docs/plan.md` restates
many of them again. The landed edit kept all 17 level-2 headings (the anchors `_docs/plan.md` cites
at `:1921`, `:1977`, `:2821`), the 13 error codes and the 13-row File Ownership table — because
P0-10 is closed with 20 frozen ACs that grade `AGENTS.md` structurally — and compressed duplicated
prose into pointers.
