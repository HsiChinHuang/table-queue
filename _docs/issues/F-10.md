## Goal

Build `/board/:branchId` public board page that displays waitlist status to the public without authentication.

## Context

Public board is a read-only page that shows current waitlist status at a glance. It is used by guests waiting outside the restaurant to see who is being called and join the waitlist via QR code.

- Related: F-05 (routing/layout), F-06 (components)
- Design: `_docs/ui.md` section 6.4
- API: `_docs/openapi.yaml` GET /board/:branchId
- Config: `_docs/specs.md` section 18 (environment variables)

## Implementation notes

- Create `frontend/src/pages/public/BoardPage.tsx`
- Export pure functions for testability:
  - `buildJoinUrl(publicBaseUrl: string, branchId: string|number): string`
  - `limitRecentCalls<T>(list: T[]): T[]` (returns first 3 items)
- Import `QRCode` from `qrcode.react` (SW adds via `npm --prefix frontend install qrcode.react`)
- Use `useParams` from react-router to get `branchId`
- Use `useBoard(branchId)` hook from F-03
- Use `QRCode` component with `value={buildJoinUrl(publicBaseUrl, branchId)}`
- Polling: use TanStack Query's `refetchInterval: 5000`
- Layout: use Tailwind grid/flex with `md:grid-cols-2` for responsive
- Styling: follow `_docs/ui.md` section 6.4 and design tokens from `_docs/ui.md` sections 2-4
- Empty state: "No one has been called yet." when no current call
- Loading state: use `LoadingSkeleton` variant `board`
- Error state: show error message from `_docs/specs.md` section 11
