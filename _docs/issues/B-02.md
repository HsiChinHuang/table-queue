## Goal

Create SQLAlchemy 2.0 models for Restaurant, Branch, Table, WaitlistEntry, Settings with proper enums, constraints, and indexes matching `_docs/specs.md` section 6.

## Context

This issue implements the data layer for the TableQueue backend. The models must use SQLAlchemy 2.0 style with `Mapped[]` and `mapped_column()`, follow the data model specification in `_docs/specs.md` section 6, and integrate with the existing `Base` from `backend/app/database.py` created in B-01.

The models will be used by all subsequent backend issues (B-03 schemas, B-04 auth, B-05 waitlist services, etc.). Proper constraints and indexes are critical for data integrity and query performance.

Design reference: `_docs/specs.md` Section 6 (Data Model)
API reference: `_docs/openapi.yaml` schemas
Base class: `backend/app/database.py` Base from B-01

## Implementation notes

**Files to create**:
- `backend/app/models.py` - SQLAlchemy 2.0 models

**Key design decisions**:
- Use SQLAlchemy 2.0 style with `Mapped[]` type hints and `mapped_column()` for column definitions
- Use `Enum` from SQLAlchemy for status enums (WaitlistStatus, TableStatus, WaitlistSource, CancelledReason)
- Use `uuid.UUID` with `default=uuid.uuid4` for UUID primary keys (Table.id, WaitlistEntry.id)
- Use `datetime.now(timezone.utc)` as default for created_at fields
- Use `onupdate=datetime.now(timezone.utc)` for updated_at fields
- Define unique constraints using `UniqueConstraint` from sqlalchemy
- Define indexes using `Index` from sqlalchemy
- All models inherit from `Base` imported from `app.database`

**Dependencies**:
- B-01: Provides Base, engine, SessionLocal from database.py

**Foreign key relationships**:
- Branch.restaurant_id → Restaurant.id
- Table.branch_id → Branch.id
- WaitlistEntry.branch_id → Branch.id
- WaitlistEntry.table_id → Table.id (nullable)
- Settings.branch_id → Branch.id (unique)

**Enum definitions**:
- WaitlistStatus: WAITING, CALLED, SEATED, DONE, NO_SHOW, CANCELLED
- TableStatus: AVAILABLE, OCCUPIED, CLEANING
- WaitlistSource: CUSTOMER, STAFF
- CancelledReason: CUSTOMER, STAFF, CLOSED_DAY, RESET

**Unique constraints**:
- Table: (branch_id, label)
- WaitlistEntry: (branch_id, business_date, queue_prefix, seq)
- Settings: branch_id

**Indexes**:
- WaitlistEntry: (branch_id, business_date, status), (branch_id, sort_order)
- Table: (branch_id, is_active, status)
