## Goal

Create `PublicLayout`, `StaffLayout`, routing constants in `routes.ts`, `App.tsx` wiring, `NotFoundPage`, and `DevBadge` component.

## Context

This issue implements the foundational routing and layout structure for TableQueue. It defines:
- Route constants in `frontend/src/routes.ts`
- `App.tsx` with React Router v6 setup
- `PublicLayout` for guest-facing pages (background `#FFFBF5`, header "TableQueue", footer, `DevBadge`)
- `StaffLayout` for staff/admin pages (background `#F8FAFC`, nav with Waitlist/Tables/Settings, logout, `DevBadge`, token-check redirect)
- `NotFoundPage` for 404 handling
- `DevBadge` component shown only in development

Related: `_docs/ui.md` section 6 (pages), `_docs/specs.md` (route table), `_docs/openapi.yaml` (API contract).

## Implementation notes

- Use React Router v6 (pinned in `package.json`) - v6 works on Node 18 + React 18
- `routes.ts` exports string constants for all routes
- `App.tsx` uses `createBrowserRouter` + `RouterProvider`
- `PublicLayout` wraps guest routes (`/join`, `/status/:queueNumber`, `/lookup`, `/board/:branchId`)
- `StaffLayout` wraps staff/admin routes (`/staff/login`, `/staff/waitlist`, `/staff/tables`, `/admin/settings`)
- `StaffLayout` checks `staffStore.token` and redirects to `/staff/login` if missing
- `DevBadge` conditionally rendered with `import.meta.env.DEV`
- Background colors: `#FFFBF5` (guest), `#F8FAFC` (staff) from `_docs/ui.md` section 2
- Nav labels: "Waitlist", "Tables", "Settings" from `_docs/ui.md` section 6
- `NotFoundPage` button links to `/join?branch=1`
