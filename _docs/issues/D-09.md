## Goal

`_docs/documents.md` stops claiming reachability no role file grants, gains a row for every file the
agent guide's Read-These-Files-First list requires every role to read, and becomes self-proving: every
path it names resolves in the same run, its unreadability claim matches its own content, and it is
registered in the two places that carry the `documents.md` -> owner `PM` row (root `AGENTS.md` after
D-05's fix, and `CONTRIBUTING.md`). The file keeps its current shape and stays the single authoritative
document index.

## Context

`AGENTS.md`'s Pointers list sends every role to `_docs/documents.md` ("Documents index"). Four
defects, all measured in this checkout at 6424460, make that pointer lie. AC-1..AC-4 each repair one of
them; AC-5 scopes the repair to the one file.

**1. Phantom grants (AC-1).** The role rows cite files no role file names. Measured here:

- `grep -lE -- 'testing-guidelines|commands\.md' _docs/team/*.md` prints nothing (rc 1), so the SW row
  (`_docs/documents.md:15`) and the QA row (`:16`) each grant two documents - `_docs/testing-guidelines.md`
  and `_docs/commands.md` - that `_docs/team/sw.md` and `_docs/team/qa.md` never mention. `_docs/commands.md`
  is in fact pointed at by root `AGENTS.md` as a pointer and by `_docs/team/orchestrator.md` as
  Orchestrator-only.
- `grep -l 'design-system' _docs/team/*.md` prints only `_docs/team/sa.md`, yet the matrix grants
  `_docs/design-system.md` to SA (line 13, "read+write") and to SW (line 15) as well.
- Symmetrically, four role rows name `_docs/requirements.md` while `_docs/team/pm.md`,
  `_docs/team/sw.md` and `_docs/team/qa.md` do not name it at all, and `_docs/team/pm.md` names
  `_docs/task-template.md` while line 14 grants it to nothing outside the PM row (that one happens to
  agree). The direction that strands a role is the one that matters: a row that grants a file nobody
  reads is decoration, a grant a role file *does* make with no row hides a document from the index that
  AGENTS.md tells everyone to trust.

Either the row matches the role file or the row goes. That is decidable in one grep per pair, in both
directions.

**2. Missing rows (AC-2).** AGENTS.md section 3 "Read These Files First" (surviving verbatim in

**3. Unresolvable paths (AC-3).** `README.md` and `CONTRIBUTING.md` are not in any read section, and

1 (`_docs/documents.md` once indexed the guide as `_docs/AGENTS.md`, a path that has never existed).
AC-3 makes the index self-proving for every path it names, so a broken path cannot survive another
edit.

**4. The contradiction inside the file (AC-4).** The section heading `_docs/documents.md:3` reads

## Acceptance criteria

- [ ] **AC-1** Every document grant in the role section of `_docs/documents.md` is paired with the same grant in that role's file under `_docs/team/`, in both directions: no row grants what the role file does not read (token `row-grants-unread`), and no file the role file reads is missing from its row (token `index-misses-role-read`). Bare role-file mentions do not count as grants: a path is a role read only when the role file wraps it in backticks, or when it names a role brief under `_docs/team/` in full. `_docs/team/orchestrator.md` is excluded because the Orchestrator's reads live in the "Read by Orchestrator only" section, which AC-4 settles.

```bash
FILE=_docs/documents.md
test -f "$FILE" || { echo "FAIL AC-1: $FILE not found"; exit 0; }
test -d _docs/team || { echo "FAIL AC-1: _docs/team not found"; exit 0; }
  MISS=""
for role in sa pm sw qa; do
  TF=_docs/team/$role.md
  test -f "$TF" || { echo "FAIL AC-1: $TF not found"; exit 0; }
  RT=$(grep -oE '_docs/team/[A-Za-z0-9._-]+|`_docs/[A-Za-z0-9._/-]+`' "$TF" | sed 's/^_docs\/team\//team\//; s/^`\(_docs\/[^`]*\)`$/\1/' | sed 's/^_docs\///; s/`$//' | grep -v '^issues/' | sort -u | tr '\n' ' ')
  UP=$(printf '%s' "$role" | tr '[:lower:]' '[:upper:]')
  ROW=$(awk -v pre="- $UP" -v pre2="* $UP" 'index($0, pre) == 1 || index($0, pre2) == 1 { print substr($0, index($0, ":") + 2); exit }' "$FILE")
  if [ -z "$ROW" ]; then
    MISS="${MISS}${role}/row-missing; "
    continue
  fi
  MX=$(echo "$ROW" | grep -oE '_docs/team/[A-Za-z0-9._-]+|_docs/[A-Za-z0-9._/-]+' | sed 's/^_docs\/team\//team\//' | sed 's/^_docs\///' | grep -v '^issues/' | sort -u | tr '\n' ' ')
  for f in $RT; do
    echo "$MX" | tr ' ' '\n' | grep -qxF -- "$f" || MISS="${MISS}${role}/index-misses-role-read:${f}; "
  done
  for f in $MX; do
    echo "$RT" | tr ' ' '\n' | grep -qxF -- "$f" || MISS="${MISS}${role}/row-grants-unread:${f}; "
  done
done
if [ -z "$MISS" ]; then
  echo "PASS AC-1: every sa/pm/sw/qa grant in the index is paired with a matching read in _docs/team, both directions"
else
  echo "FAIL AC-1: ${MISS}"
fi
```
